# GLOSSARY — TỪ ĐIỂN THUẬT NGỮ PHỎNG VẤN THEO CHƯƠNG

Nguồn nội dung cho `GlossaryTerm[]` (xem schema ở **[book_data_model_guide.md](../guides/book_data_model_guide.md)**). Mỗi thuật ngữ có id dạng `term-{kebab-case}`, gắn với 1+ chương, mô tả ngắn, và link tham khảo (`mdnUrl` — với thuật ngữ không có trang MDN, trỏ TypeScript Handbook / React docs / Wikipedia thay thế). 37 mục, nhóm theo chương giới thiệu khái niệm đó.
